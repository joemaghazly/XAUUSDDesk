Indicators

This is documentation, not a live tool — these run on your TradingView chart, not in a browser here. Each entry is what it's for in the actual framework, not a generic description.

01
Asian Range BoxLive on chart

Draws the 01:00–10:00 Beirut high and low as a box on the chart.

Used for: the pre-session read (range vs. Daily ATR → Compression / Normal / Stretched / Extended), and as the boundary that both the London-experiment trigger and the execution-window entries need an actual break or reclaim of — not a plain EMA/VWAP cross.

02
EMA 21 / 45 / 100Live on chart

Three exponential moving averages on the working timeframe.

Used for: the 1H-close filter before entering (candle closes above/below EMA21 confirms direction) and as one of the pullback references during the execution window.

03
VWAP — Session AnchoredLive on chart

VWAP re-anchored at 15:00 Beirut, when the execution window opens.

Used for: the reversal-entry distance filter — price sitting roughly 35–50% of Daily ATR away from the anchor. Continuation entries don't use this check.

04
RSI (14)Live on chart

Standard 14-period RSI.

Used for: the Bullet 2 exhaustion exit at 71 (long) / 29 (short) — an exit signal on the runner, not an entry filter.

05
Bollinger Bands (20, 2)Live on chart

20-period, 2 standard deviations, read on the 5-minute chart.

Used for: the last check before entering during the execution window — part of the pre-entry checklist, alongside the pullback and boundary confirmations.

These already exist and are running — this page is a reference for what each one is doing and why, not a build. If any of them need adjusting (alerts, visual tweaks, an additional plot), say which one and that's a normal edit, not a rebuild.
Nothing on this page reads your chart or any live price — it's a written reference, kept next to the Journal and Session Board so the reasoning behind each indicator lives in the same place as the rules that use it.
